# 12. 表单处理

> 掌握 React 中表单数据的获取、验证与提交

## 学习目标

- 理解受控组件与非受控组件的区别
- 掌握表单验证与提交的处理方式
- 了解主流表单库的使用

## 内容结构

### 💡 概念（What & Why）

- **受控组件（Controlled）**：表单数据由 React state 管理，完全控制表单行为
- **非受控组件（Uncontrolled）**：表单数据由 DOM 管理，使用 ref 获取值

### ⚙️ 用法（How）

- 受控组件：`value` + `onChange` 绑定
- 非受控组件：`useRef` 获取表单值
- 表单验证策略：实时验证、提交时验证
- 表单库推荐：
  - **React Hook Form** —— 高性能，最小重渲染
  - **Formik** —— 功能丰富，易于使用
  - **Yup / Zod** —— 表单验证 schema

### 🛠️ 实践（Do）

- 注册表单 Demo
- 推荐练习：多步表单、动态表单字段

### 🔗 扩展（Think & Connect）

- 表单性能优化
- 无障碍表单设计
