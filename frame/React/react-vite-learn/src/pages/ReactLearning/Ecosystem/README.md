# 18. 生态系统

> React 生态全景 —— UI 库、状态管理、数据获取、工具链与部署

## 学习目标

- 了解 React 生态中主流的库和工具
- 能够根据项目需求选择合适的技术方案
- 掌握从开发到部署的完整工具链

## 内容结构

### 💡 概念（What & Why）

- React 只负责 UI 层，生态库补齐其他能力
- 选型原则：按需选择、社区活跃度、学习成本

### ⚙️ 用法（How）

- **UI 组件库**：Ant Design、Material-UI、Chakra UI、Tailwind CSS
- **状态管理**：Redux Toolkit、Zustand、Jotai、Recoil
- **数据获取**：React Query / TanStack Query、SWR、Apollo Client
- **开发工具**：React DevTools、ESLint、Prettier、Vite
- **部署平台**：Vercel、Netlify、AWS Amplify

### 🛠️ 实践（Do）

- 生态对比 Demo
- 推荐练习：用不同 UI 库搭建同一页面、对比状态管理方案

### 🔗 扩展（Think & Connect）

- 技术栈选型决策指南
- 未来趋势：React Server Components、Signals、Compiler
