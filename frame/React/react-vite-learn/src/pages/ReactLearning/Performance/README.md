# 13. 性能优化

> React 应用的性能优化策略与最佳实践

## 学习目标

- 掌握减少不必要重渲染的方法
- 理解代码分割与懒加载
- 能够诊断和优化 React 应用性能

## 内容结构

### 💡 概念（What & Why）

- React 重渲染机制与性能瓶颈
- 性能优化的核心思路：减少渲染次数、降低渲染成本

### ⚙️ 用法（How）

- **减少重渲染**：
  - `React.memo` —— 记忆化组件
  - `useMemo` —— 记忆化计算结果
  - `useCallback` —— 记忆化回调函数
- **代码分割**：
  - `React.lazy` —— 懒加载组件
  - `Suspense` —— 加载状态管理
  - 路由级别的代码分割
- **列表优化**：唯一稳定的 `key`、虚拟列表（`react-window`）
- **其他**：避免内联对象/函数、生产构建、图片懒加载

### 🛠️ 实践（Do）

- 性能对比 Demo
- 推荐练习：长列表优化、组件 memo 化

### 🔗 扩展（Think & Connect）

- React DevTools Profiler 的使用
- Web Vitals 性能指标
