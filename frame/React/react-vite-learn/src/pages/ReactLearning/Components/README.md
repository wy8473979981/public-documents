# 3. 组件基础

> React 应用的基本构建块，学习如何创建、组合和复用组件

## 学习目标

- 掌握函数组件的编写方式
- 理解组件的组合与复用
- 了解类组件与函数组件的区别

## 内容结构

### 💡 概念（What & Why）

- 组件是 React 应用的基本构建块
- 两种组件类型：
  - 函数组件 —— 使用普通 JavaScript 函数定义（推荐）
  - 类组件 —— 使用 ES6 class 定义（现已较少使用）
- 组件特点：可复用、可组合、独立管理状态

### ⚙️ 用法（How）

- 函数组件的定义与使用
- 组件的导入与导出
- 组件的嵌套与组合
- 组件的 Props 传递

### 🛠️ 实践（Do）

- 创建自定义组件 Demo
- 推荐练习：卡片组件、布局组件、可复用按钮组件

### 🔗 扩展（Think & Connect）

- 组件设计原则（单一职责、高内聚低耦合）
- 组件目录组织方式
